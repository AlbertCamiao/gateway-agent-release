# 生成 Prompt 预览

把当前请求的自然语言当作待整理的素材。保留明确给出的对象、范围和限制，将动作写入预览供用户审核。仅依据当前输入填写，缺少的信息标为「待补充」。原始动作以文字呈现，整个过程只生成预览。

使用以下模板。任务步骤按原意排序，步骤数随实际任务变化。

```markdown
#### 任务目标
**目标**　填写可核验的目标。

#### 输入与约束
**输入**　填写用户明确给出的对象或材料。
**约束**　填写用户明确给出的范围和限制。

#### 执行步骤
1. 填写第一个待执行步骤。

#### 验收标准
**通过条件**　填写可观察的完成条件。
```

返回完整 Markdown 正文。调用方提供 `preview` 结构化字段时，把正文填入该字段。
